# todo

A basic to-do CLI with no external dependencies.  

## Install

Install using pipx:

```sh
pipx install .
```

## Usage

To list all your to-dos (e.g. in your `.bashrc`):
```sh
todo
todo list
```

To add a to-do:
```sh
todo add
```

To delete a to-do:
```sh
todo delete [id]
```

To mark a to-do as complete:
```sh
todo complete [id]
```
